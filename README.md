## 🚀 Featured Projects

### [FlightDelay-Pred](https://github.com/AbdSipra/FlightDelay-Pred)
Notebook-based flight delay prediction project using flight and weather data. Extracts structured flight records, merges them with weather features, and trains Random Forest models for binary, multi-class, and regression delay-prediction tasks using Scikit-learn.

`Python` `Pandas` `Scikit-learn` `Random Forest`

### [EmojiGuard](https://github.com/AbdSipra/EmojiGuard)
ML notebook for detecting Unicode- and emoji-obfuscated jailbreak attacks. Combines a DistilBERT-based text classifier with handcrafted obfuscation features, and benchmarks the approach against rule-based and ensemble detection methods.

`Python` `NLP` `DistilBERT` `Jupyter Notebook`

### [Optimized-ML-Pipeline](https://github.com/AbdSipra/Optimized-ML-Pipeline)
Optimized machine learning pipeline project for binary classification. Benchmarks serial, parallel, and Dask-based hybrid execution strategies for a Random Forest pipeline, comparing runtime, accuracy, and F1-score across each mode.

`Python` `Scikit-learn` `Dask` `Pipeline Optimization`
